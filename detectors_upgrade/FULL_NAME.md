## Проблема 1: ФИО в нижнем регистре не маскируется

**Тест-кейс:** `fio_03` — «сидоров петр алексеевич подал заявку» (`must_mask: true`)

**Ожидание:** ФИО должно быть замаскировано.
**Факт:** не маскируется (FAIL).

**Причина:** в `accept()` (строка 65) есть проверка
`!Character.isUpperCase(words[0].charAt(0))` — если первое слово не с заглавной
буквы, фрагмент отклоняется. Regex сам по себе case-insensitive, но `accept`
убивает нижний регистр.

**Воспроизведение:**
```bash
cd blackBox && python3 test_runner.py --url http://161.104.16.21:8080/persmasker --skip-validation --skip-latency --skip-large
# в отчёте: [FAIL] [fio] fio_03: ФИО в нижнем регистре
```

**Решение:** убрать требование заглавной буквы в `accept()`, либо разрешить
нижний регистр (например, проверять, что слово не является служебным, без
проверки регистра).

## Проблема 2: ложное срабатывание на исторических личностях

**Тест-кейс:** `fio_09` — «Пётр Первый основал Санкт-Петербург» (`must_mask: false`)

**Ожидание:** не маскировать (не ПД).
**Факт:** маскируется (FAIL).

**Причина:** «Пётр» отсутствует в `EXCLUSIONS` (строка 51). Словарь исключений
содержит только писателей/поэтов, но не исторических деятелей.

**Воспроизведение:**
```bash
cd blackBox && python3 test_runner.py --url http://161.104.16.21:8080/persmasker --skip-validation --skip-latency --skip-large
# в отчёте: [FAIL] [fio] fio_09: Упоминание исторической личности (не ПД)
```

**Решение:** расширить `EXCLUSIONS` историческими/известными личностями
(Пётр, Иван Грозный, Ленин, Сталин, Гагарин и т.п.), либо добавить контекстную
проверку «известная личность».

## Проблема 3: ложное срабатывание на обычных словах (не ФИО)

**Тест-кейсы:**
- `dob_10` — «Совещание назначено на 15.03.2024» (`must_mask: false`)
- `phone_08` — «Позвоните по номеру 8800» (`must_mask: false`)

**Ожидание:** не маскировать (не ПД).
**Факт:** маскируется как ФИО (FAIL).

**Причина:** три слова с заглавной буквы («Совещание назначено на»,
«Позвоните по номеру») матчатся regex `FULL_WORD\s+(FULL_WORD|INITIAL){1,2}`
как ФИО. Первые слова нет в `ROLE_WORDS`, поэтому `accept()` принимает
фрагмент. Результат маскирования (проверено запросом к серверу):
- `dob_10` → `"С. н. н. 15.03.2024"`
- `phone_08` → `"П. п. н. 8800"`

**Воспроизведение:**
```bash
curl -s -X POST http://161.104.16.21:8080/persmasker/process \
  -H "Content-Type: application/json" \
  -d '{"payload":"Совещание назначено на 15.03.2024","payload_id":"probe"}'
# результат: {"result":"С. н. н. 15.03.2024"} — слова замаскированы, это ложное срабатывание
```

**Решение:** расширить `ROLE_WORDS` служебными/обычными словами, либо добавить
проверку, что слова образуют правдоподобное ФИО (например, отчество оканчивается
на -ич/-овна/-евна, или имя входит в словарь имён). Это сложная задача — нужен
баланс между полнотой и точностью.

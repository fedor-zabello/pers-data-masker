## Проблема 1: не маскируется формат «77 12 345678»

**Тест-кейсы:**
- `license_01` — «Водительское удостоверение 77 12 345678» (`must_mask: true`)
- `license_03` — «водительское удостоверение 77 12 345678» (`must_mask: true`)
- `license_06` — «ВУ 77 12 345678 выдано» (`must_mask: true`)

**Ожидание:** серия и номер ВУ должны быть замаскированы.
**Факт:** не маскируются (FAIL).

**Причина:** regex `LICENSE_REGEX` (строка 15): `\d{4}[\s\-]?\d{6}` ожидает
4 цифры подряд, затем опционально разделитель, затем 6 цифр. Но формат
«77 12 345678» — это `77` + пробел + `12` + пробел + `345678` (два пробела
внутри). Паттерн `\d{4}` не матчит «77 12» (между ними пробел).

**Воспроизведение:**
```bash
cd blackBox && python3 test_runner.py --url http://161.104.16.21:8080/persmasker --skip-validation --skip-latency --skip-large
# в отчёте: [FAIL] [drivers_license] license_01/03/06
```

**Решение:** изменить regex на `\d{2}[\s\-]?\d{2}[\s\-]?\d{6}` — допускать
разделители между парами цифр серии.

## Проблема 2: контекст не ловит аббревиатуру «ВУ»

**Тест-кейс:** `license_06` — «ВУ 77 12 345678 выдано» (`must_mask: true`)

**Ожидание:** серия и номер ВУ должны быть замаскированы.
**Факт:** не маскируется (FAIL).

**Причина:** `CONTEXT` (строка 17) содержит `в/у` (со слэшем), но во входе
аббревиатура «ВУ» без слэша. Паттерн `в/у` не матчит «ВУ».

**Воспроизведение:**
```bash
cd blackBox && python3 test_runner.py --url http://161.104.16.21:8080/persmasker --skip-validation --skip-latency --skip-large
# в отчёте: [FAIL] [drivers_license] license_06: ВУ с аббревиатурой ВУ
```

**Решение:** добавить в `CONTEXT` вариант `\bВУ\b` (без слэша).

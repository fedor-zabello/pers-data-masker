## Проблема 1: не маскируется телефон с точками

**Тест-кейс:** `phone_07` — «Телефон: +7.912.345.67.89» (`must_mask: true`)

**Ожидание:** телефон должен быть замаскирован.
**Факт:** не маскируется (FAIL).

**Причина:** regex `PHONE_REGEX` (строка 17) допускает разделители только
`[\s\-]` и `[()\s\-]` (строка 20). Точка `.` не входит в список разделителей,
поэтому «+7.912.345.67.89» не матчится. Проверено запросом к серверу — телефон
не замаскирован.

**Воспроизведение:**
```bash
cd blackBox && python3 test_runner.py --url http://161.104.16.21:8080/persmasker --skip-validation --skip-latency --skip-large
# в отчёте: [FAIL] [email_phone] phone_07: Телефон с точками
```

**Решение:** добавить точку `.` в список разделителей в `PHONE_REGEX` и
`SEPARATOR` (например, `[\s\-.()]`).

## Проблема 2: ложное срабатывание на коротком номере

**Тест-кейс:** `phone_08` — «Позвоните по номеру 8800» (`must_mask: false`)

**Ожидание:** не маскировать (не ПД).
**Факт:** маскируется (FAIL).

**Важно:** это НЕ проблема телефона. Проверено запросом к серверу — номер `8800`
не маскируется, а маскируются слова «Позвоните по номеру» как ФИО
(результат `"П. п. н. 8800"`). Это ложное срабатывание `FullNameDetector`.

**Решение:** исправление в `FullNameDetector` (см. `FULL_NAME.md`, проблема 3).
В этом файле отдельного исправления не требуется.

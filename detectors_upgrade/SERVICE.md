## Проблема 1: идемпотентность — третий запрос с тем же payload_id ломается

**Тест-кейс:** `idempotency_02` — «Идемпотентность: третий запрос с тем же id»

**Ожидание:** повторные запросы с тем же `payload_id` безопасны и возвращают
исходную строку.
**Факт:** третий запрос возвращает мусор (FAIL).

**Сценарий теста (`run_idempotency_test`):**
1. Запрос 1: `process(original, payload_id)` → маска
2. Запрос 2: `process(masked, payload_id)` → демаскирование (ожидается original)
3. Запрос 3: `process(masked, payload_id)` → демаскирование (ожидается original)

**Причина:** после демаскирования запись в `CorrelationStore` (Caffeine, TTL
10 мин) вероятно удаляется/потребляется. Третий запрос с той же маской уже не
находит запись и трактует маску как новый текст для маскирования → мусор.

**Воспроизведение:**
```bash
PID="idem-test-1"
curl -s -X POST http://161.104.16.21:8080/persmasker/process -H "Content-Type: application/json" \
  -d "{\"payload\":\"Иванов Иван Иванович, паспорт 4509 123456\",\"payload_id\":\"$PID\"}"
# 1-й: {"result":"И. И. И., паспорт 45** ****56"}
# 2-й (с маской): возвращает исходную строку
# 3-й (с маской): возвращает мусор вместо исходной строки
```

**Решение:** сделать демаскирование идемпотентным — не удалять запись из стора
после демаскирования (или не трактовать повторный запрос с той же маской как
новое маскирование). Проверить логику `ProcessService.process` и
`CorrelationStore`.

## Проблема 2: некорректный Content-Type возвращает 500 вместо 4XX

**Тест-кейс:** `validation_03` — «Некорректный Content-Type»

**Ожидание:** запрос с `Content-Type: text/plain` должен быть отклонён кодом
4XX (400–499).
**Факт:** возвращается **500** (FAIL).

**Причина:** при `Content-Type: text/plain` Spring не может распарсить JSON в
`@RequestBody`, но исключение не обрабатывается как клиентская ошибка (4XX),
а уходит как 500. Нужно обработать `HttpMediaTypeNotSupportedException` /
`HttpMessageNotReadableException` в `ApiExceptionHandler`.

**Воспроизведение:**
```bash
curl -s -o /dev/null -w "%{http_code}\n" -X POST http://161.104.16.21:8080/persmasker/process \
  -H "Content-Type: text/plain" -d '{"payload":"тест","payload_id":"vt3"}'
# результат: 500 (ожидается 4XX)
```

**Решение:** добавить обработчик исключений для неверного Content-Type и
нераспарсенного тела в `ApiExceptionHandler`, возвращающий 400/415.

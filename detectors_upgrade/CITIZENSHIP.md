## Проблема 1: не маскируется «Гражданство: Россия» (двоеточие)

**Тест-кейсы:**
- `citizenship_02` — «Гражданство: Россия» (`must_mask: true`)
- `citizenship_03` — «Гражданство: РФ» (`must_mask: true`)
- `citizenship_05` — «гражданство: российская федерация» (`must_mask: true`)

**Ожидание:** гражданство должно быть замаскировано.
**Факт:** не маскируется (FAIL).

**Причина:** regex `CITIZENSHIP_REGEX` (строка 23):
`(?:гражданин|гражданство|гражданка)\s+(?:...)` — требует пробел сразу после
слова «гражданство», но во входе стоит двоеточие «Гражданство: Россия».
Двоеточие не допускается.

**Воспроизведение:**
```bash
cd blackBox && python3 test_runner.py --url http://161.104.16.21:8080/persmasker --skip-validation --skip-latency --skip-large
# в отчёте: [FAIL] [birthplace_citizenship] citizenship_02/03/05
```

**Решение:** разрешить необязательное двоеточие/дефис между словом и страной:
`гражданство\s*:?\s*(?:...)`.

## Проблема 2: не маскируется «Республика Казахстан»

**Тест-кейс:** `citizenship_04` — «Гражданство: Республика Казахстан» (`must_mask: true`)

**Ожидание:** гражданство должно быть замаскировано.
**Факт:** не маскируется (FAIL).

**Причина:** в словаре `COUNTRIES` (строка 15) есть только «Казахстана»
(родительный падеж), но нет варианта «Республика Казахстан» (именительный с
префиксом «Республика»).

**Воспроизведение:**
```bash
cd blackBox && python3 test_runner.py --url http://161.104.16.21:8080/persmasker --skip-validation --skip-latency --skip-large
# в отчёте: [FAIL] [birthplace_citizenship] citizenship_04: Гражданство иностранное
```

**Решение:** добавить в `COUNTRIES` варианты «Республика X» для стран, где это
применимо (Казахстан, Беларусь, Узбекистан и т.д.).

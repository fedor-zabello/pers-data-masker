# detectors_upgrade — проблемы детекторов ПД

Папка с описанием проблем детекторов персональных данных и способами их
воспроизведения. Каждый файл соответствует одному типу ПД и может быть
делегирован отдельному агенту.

## Как читать файлы

Каждый файл содержит:
- **Статус исправления** — чекбоксы с маркером `<!-- MARKER: FIXED -->`.
  Агент отмечает `[x]` после исправления проблемы.
- **Проблема** — описание, тест-кейс, ожидание/факт, причина.
- **Воспроизведение** — команда для проверки.
- **Решение** — рекомендация по исправлению.
- **Связанные тест-кейсы** — что не трогать (чтобы не сломать).

## Индекс файлов

| Файл | Тип ПД | Детектор | Проблем |
|------|--------|----------|---------|
| [FULL_NAME.md](FULL_NAME.md) | ФИО | `FullNameDetector` | нижний регистр, ложные срабатывания (исторические личности, обычные слова) |
| [INN.md](INN.md) | ИНН | `InnDetector` | чек-сумма отклоняет валидный ИНН |
| [CITIZENSHIP.md](CITIZENSHIP.md) | Гражданство | `CitizenshipDetector` | двоеточие, «Республика X» |
| [CARD_HOLDER.md](CARD_HOLDER.md) | Держатель карты | `CardHolderDetector` | ALL-CAPS, нижний регистр, контекст |
| [CARD_NUMBER.md](CARD_NUMBER.md) | Номер карты | `CardNumberDetector` | чек-сумма Луна отклоняет тестовый номер |
| [DRIVER_LICENSE.md](DRIVER_LICENSE.md) | Водительское удостоверение | `DriverLicenseDetector` | формат «77 12 345678», контекст «ВУ» |
| [BIRTH_DATE.md](BIRTH_DATE.md) | Дата рождения | `BirthDateDetector` | американский формат, ложное срабатывание |
| [PHONE.md](PHONE.md) | Телефон | `PhoneDetector` | точки-разделители, ложное срабатывание |
| [PASSPORT.md](PASSPORT.md) | Паспорт | `PassportDetector` | серия с точкой |
| [ADDRESS.md](ADDRESS.md) | Адрес | `AddressDetector` | расхождение версий серверов (деплой) |
| [SERVICE.md](SERVICE.md) | — (сервис) | `ProcessService`/`CorrelationStore` | идемпотентность, Content-Type 500 |

## Типы без проблем

Email, CVV, ПИН, место рождения — см. [NO_ISSUES.md](NO_ISSUES.md).

```bash
cd blackBox && python3 test_runner.py --url http://161.104.16.21:8080/persmasker
```

## Приоритет (по эффекту)

1. `CITIZENSHIP.md` — +4 кейса (простые правки regex)
2. `CARD_HOLDER.md` — +2 кейса
3. `DRIVER_LICENSE.md` — +2 кейса
4. `FULL_NAME.md` — +1 кейс, −3 ложных срабатывания (самое ценное)
5. `INN.md`, `CARD_NUMBER.md` — +2 кейса каждый (ослабить чек-суммы)
6. `PHONE.md`, `PASSPORT.md`, `BIRTH_DATE.md` — +1 кейс каждый
7. `SERVICE.md` — идемпотентность + обработка ошибок
8. `ADDRESS.md` — задача деплоя, не код

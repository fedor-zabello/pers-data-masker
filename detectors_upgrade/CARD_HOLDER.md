## Проблема 1: не маскируется имя держателя в верхнем регистре

**Тест-кейс:** `cardholder_01` — «Имя держателя карты: IVAN IVANOV» (`must_mask: true`)

**Ожидание:** имя держателя должно быть замаскировано.
**Факт:** не маскируется (FAIL).

**Причина:** regex `HOLDER_REGEX` (строка 17): `[A-Z][a-z]+\s+[A-Z][a-z]+`
требует строчные буквы после первой заглавной. «IVAN IVANOV» — все заглавные,
не матчится.

**Воспроизведение:**
```bash
cd blackBox && python3 test_runner.py --url http://161.104.16.21:8080/persmasker --skip-validation --skip-latency --skip-large
# в отчёте: [FAIL] [inn_card] cardholder_01: Имя держателя карты
```

**Решение:** добавить альтернативу для ALL-CAPS: `[A-Z]{2,}` (например,
`(?:[A-Z][a-z]+|[A-Z]{2,})\s+(?:[A-Z][a-z]+|[A-Z]{2,})`).

## Проблема 2: не маскируется имя держателя в нижнем регистре

**Тест-кейс:** `cardholder_02` — «Имя держателя: ivan ivanov» (`must_mask: true`)

**Ожидание:** имя держателя должно быть замаскировано.
**Факт:** не маскируется (FAIL).

**Причина:** regex `HOLDER_REGEX` требует заглавную букву в начале каждого слова.
«ivan ivanov» — нижний регистр, не матчится.

**Воспроизведение:**
```bash
cd blackBox && python3 test_runner.py --url http://161.104.16.21:8080/persmasker --skip-validation --skip-latency --skip-large
# в отчёте: [FAIL] [inn_card] cardholder_02: Имя держателя карты в нижнем регистре
```

**Решение:** разрешить нижний регистр в regex (например, `[A-Za-z]+`), либо
добавить отдельную ветку для нижнего регистра.

## Проблема 3: контекст не ловит «держателя карты» (родительный падеж)

**Тест-кейсы:** `cardholder_01`, `cardholder_02` (см. выше) — контекст
«Имя держателя карты» / «Имя держателя» не распознаётся.

**Причина:** `CONTEXT` (строка 19) содержит `держатель\s*карты`, но во входе
«держателя карты» (родительный падеж) и «держателя» без «карты». Паттерн
`держатель\s*карты` не матчит «держателя карты».

**Воспроизведение:** см. `cardholder_01`, `cardholder_02`.

**Решение:** расширить контекст: `держател\w*\s*карты?` (ловит «держатель»,
«держателя», «держателю»), а также просто «держател\w*».
